# 技術ミステリー小説「境界条件」シリーズ 紹介ショーリール

1080×1920（9:16）、30fps、15.00 秒、H.264 High / AAC、iPhone でそのまま再生できる。
`boundary_conditions_reel.html` が生成元（Canvas + Web Audio。主人公の写真と、使用文字だけを含む Noto Serif JP / Noto Sans JP / JetBrains Mono を埋め込み済み）。

96 BPM・24 拍：

| 秒 | 映像 | 音 |
|---|---|---|
| 0–2.5 | 事業部（民間航空機・宇宙・防衛）の画像をごく淡く流し、波形の上に「事故は、」「誰のせいでもなかった。」をタイプ | 時計の刻み、打鍵音、低い一撃とピアノ |
| 2.5–5 | 設計・製造・品証・営業の4部署のパネルが1拍ずつ 2×2 に着地。それぞれに「判断：正しい」の判 | 判を押す音、刻み |
| 5–7.5 | 4部署のパネルが寄り、間に赤い十字の空白が残る。中央に「担当者：なし / UNASSIGNED BOUNDARY」。「正しさと正しさが重なった瞬間、」「隙間が見える。」 | 上昇音、ガラスの響き、外れた一音 |
| 7.5–11.25 | 硯川澪の写真を1拍ごとにカット、解析ブラケット。「図面と、波形と、」「人の沈黙を、」「同じ解像度で読む。」／東雲重工 全社技術審査委員会 技術調査官 硯川 澪 | ハーフタイムのビート、ピアノ |
| 11.25–15 | 赤い境界線がタイトルを「境界｜条件」に割る。BOUNDARY CONDITIONS／技術ミステリー小説シリーズ／「事故は、正しさの隙間に宿る。」／13.5 秒から「カクヨムにて連載中」、右下の隅に LINE スタンプ（「確認します」）と「LINEスタンプ販売中」 | 重低音と不協和音のクラスター、余韻 |

境界条件は事業部間ではなく、設計・製造・品証・営業の部署間にある、という設定に合わせている。部署画像・事業部画像はオーナー提供。
