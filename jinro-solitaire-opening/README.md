# 人狼ソリティア オープニング動画（ショートリール）

アプリ起動時に流すオープニング動画。

## ファイル

| ファイル | 内容 |
|---|---|
| `jinro_solitaire_reel_1080x1920.mp4` | 本番用動画。H.264 High / AAC 48kHz stereo 256kbps、faststart 済み |
| `jinro_solitaire_reel.html` | 動画の生成元（Canvas + Web Audio、キー画像を埋め込み済み）。ブラウザで開くと再生できる。修正時はここを編集して再レンダリングする |
| `storyboard.jpg` | 主要フレームの一覧（0.5 / 1.1 / 1.67 / 2.57 / 3.03 / 3.33 / 4.17 / 4.97 秒） |

## 仕様

- 解像度 1080×1920（9:16 縦長）、30fps、長さ 5.00 秒、約 5MB
- 音声あり：120 BPM のビートと効果音（すべて合成音）。平均 -17 dB、ピーク -0.4 dB、音割れなし
- 最初と最後は黒からのフェードイン／フェードアウトなので、黒い画面とは継ぎ目なくつながる
- 配色：濃紺 `#0D0F1F`〜`#1B1F3B`、ゴールド `#C9A227`、オフホワイト `#F4F1E8`、人狼カードのみ真紅
- フォント：Noto Serif JP 900（タイトル・役職名）、Cinzel（英字）。映像に焼き込み済みなので、アプリ側でフォントを用意する必要はない

## Android での組み込み例

- `app/src/main/res/raw/jinro_solitaire_reel_1080x1920.mp4` に置く（ファイル名は小文字・数字・アンダースコアのみなのでそのまま使える）
- スプラッシュ画面または最初の Activity で、Media3 ExoPlayer か VideoView を使って全画面再生する
  - URI：`RawResourceDataSource.buildRawResourceUri(R.raw.jinro_solitaire_reel_1080x1920)`
  - 縦長端末では `RESIZE_MODE_ZOOM`（center-crop）にして上下左右の黒帯を出さない。重要な要素は画面中央の 1080×1700 程度に収めてある
  - 再生終了（`STATE_ENDED`）でメイン画面へ遷移する。タップでスキップできるようにするのがおすすめ
  - 端末のマナーモードや、アプリ側の「サウンドOFF」設定のときは音量を 0 にする
- 背景色は `#000000`（映像の最初と最後が黒のため、遷移で色が飛ばない）

## 注意事項・未確定事項

- 役職（占い師・騎士・村人・人狼）とカードのランク表記（Q・J・10・A）、キャッチコピー「嘘を、見抜け。」は制作側の仮の案。アプリの実際の役職やカードデザインに合わせる場合は差し替えが必要
- 3.9 秒以降に使っている狼男のキー画像は、オーナーから提供された生成画像（opening_wolf_man_realistic.png と同じもの）
